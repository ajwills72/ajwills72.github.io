The Data and Analysis Units contain research data, analysis scripts and supplementary materials. Each unit describes its own files, variables and software requirements. Start with those notes before running an analysis.

Data and scripts

  • .csv: comma-separated text data. Preserve column names and check how missing values and text fields are represented when importing.
  • .txt: plain text. Data tables may use tabs, spaces or another separator; consult the unit's analysis script for the intended import settings.
  • .R: R source code. Open it in a text editor or R environment. Download the associated data and helper scripts, and check the working directory and required packages before running it.
  • .Rproj: an RStudio project file; it does not contain the project's data or scripts.
  • .sps: SPSS syntax. Check the data paths and software requirements in the script.

Archives and documents

  • .zip: a compressed archive. Extract it before opening the files.
  • .tbz, .tar.bz2: a tar archive compressed with bzip2. Extract it with an archive utility that supports this format.
  • .tar.gz: a tar archive compressed with gzip.
  • .pdf: a document for a PDF reader.
  • .png, .jpg, .tif, .svg: image formats. SVG is a vector format; the others are raster formats.

Some units also provide experiment files for specific versions of commercial software, such as E-Prime. These require the software described on the unit's page. Older scripts may require their original package or application versions.

Keep an unchanged copy of the downloaded data. Refer to the unit's citation and any file-specific licence before reusing its materials.
